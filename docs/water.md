# 水体实现说明

目标是有连续起伏、能够看见水下细节的深青色海水。浪抵达岩岸后产生少量白水，随后散成泡孔和细丝；浪的主体保持透明。色彩、浪高和泡沫量按奇幻岛屿的画面调整。

## Tidewater 参考了什么

基础海面、光学着色和焦散来自 [tidewater 的 three.js / TSL 版 `fd6cae6`](https://github.com/dgreenheck/tidewater/tree/fd6cae6fa57343d344e5c008e1abda974c824b86)。近岸浪与泡沫参考其后来的原生 WebGPU 版 [`4811ba4`](https://github.com/dgreenheck/tidewater/tree/4811ba48d795197de5621985f404e765c0b7c0ef)，相关算法在这里改写成 TSL。

## 岛屿遮挡怎样影响浪

到达时间决定一波浪什么时候经过，另外一张静态遮挡场决定它经过岛后还剩多少幅度。遮挡场沿来浪方向及其两侧发出五条射线，检查现有岛屿岸线的阻挡，再在水域内平滑权重。近岛完全被挡住的长涌浪保留约 6% 的幅度；远离岸线后逐渐恢复外海强度。

遮挡权重先降低波形输入幅值，所以浪高、变陡程度和水粒子运动一起减弱。岩壁接触也读取接触点外侧的遮挡权重，使背浪侧少产生白水和反射。FFT 长波明显衰减，中尺度只轻微衰减，最细的风纹保留原有连续性，背浪水面仍有轻微起伏。

这部分是本项目为封闭岩岛增补的定向遮挡近似，没有求解真实衍射和完整的海浪能量输运。岸线和射线都采用有限采样，极浅的掠边接触不保证精确。当前近岸周期为 2.8 秒、基准幅值参数为 0.14 米；实际浪高还受波组、水深与遮挡影响。反射、白水扩散宽度和浪峰透光采用温和的画面设置。

## 拉远后为什么不会在固定区域生灭

原实现把额外涌浪限制在离岸 18–32 米的范围内，外海则由另一组 FFT 波纹接续。两组浪的相位不同，拉远后容易看见固定的出现与消失区域。

现在同一组成组涌浪在整片海面上推进。外海按传播相位与沿浪峰坐标读取预烘焙波形；近岸缓存只记录水深、绕岛传播、遮挡和弱反射相对于外海波形的差值。两者相加得到完整水面，几何与法线读取同一结果。波峰不会因为离岸距离达到某个阈值而被删掉。

到达时间保持未取模的连续值，在缓存边缘向全局平面波相位平滑衔接，再计算其梯度。最外侧差值严格归零，使缓存范围之外仍能按世界坐标推进，而不是钳在边缘形成停滞的波形。相位坐标烘焙仅在方向、周期或幅值变化时重算，近岸两张缓存随时间更新。

这套全局波形与局部差值的衔接是 Soomi 为远景连续性添加的处理。它仍使用 Tidewater 改编的成组、非对称浪形。波组每 14 波重复，沿浪峰每 128 米重复，默认相当于 39.2 秒的波组周期；细浪仍由独立 FFT 提供。近岸修正逐渐过渡到外海参考深度，没有求解无限范围的水深传播或完整的衍射。

## 怎样让波浪更柔和

现实海面可以同时包含本地风浪与远来涌浪，具体比例取决于海况。涌浪通常较圆顺、周期与方向较集中；风浪的浪高和间距更不齐，两者及其他来向的浪叠加后形成一组有方向、频率分布的波。存在主浪向并不意味着整片海面应当由同周期、等间距的长浪脊组成。见 [NOAA 对混合波谱的说明](https://vos.noaa.gov/MWL/apr_06/waves.shtml) 与 [NWS 海况观察手册](https://www.weather.gov/media/marine/marepreport.pdf#page=4)；后者的附录也提供实际海面照片。前一轮降低浪高与浪峰强调，改善了条带的强度，但没有解决单载频的结构限制。

当前涌浪幅值参数为 0.14 米，波组强弱系数在 55%–100% 间变化。深水波形更接近圆润的起伏，只有实际浪高与水深之比增大时才加强尖化、偏斜和横向压缩。基础 FFT 的幅度参数为 0.68、横向压缩为 0.5，细浪法线权重为 0.68；其波长、方向分布与连续时钟仍由原有频谱控制。

浪肩对细纹的最大抑制由 42% 降到 10%，减少整齐的光滑/粗糙交替带；额外的浪峰天空散射强调也减弱。波峰和波谷都有细风纹，几何、法线、折射与撞岸白水仍读取同一波形。较小的浪会自然减少接触白水，不额外强制生成固定的白线。这些数值是画面选择，并非 NOAA 给出的海况标准。

## 当前规律感的来源与后续方向

[ShoreWaves.ts](../src/ocean/ShoreWaves.ts) 的额外长浪共用 2.8 秒的基础周期和一个来浪方向；14 波的强弱变化主要改变幅值，沿浪脊的相位扰动也很小。将这一组成组浪连续延伸至外海，消除了固定的生灭区域，但同时把近岸波列的秩序带到了整个海面。从低视角看，连续浪肩改变反射方向，更容易显出近似平行的亮暗长带。细碎 FFT 波纹叠加在上面，仍不足以改变这层长浪的基本间距。

[OceanFFT.ts](../src/ocean/OceanFFT.ts) 已有不同波数、方向和确定性初相位的频谱，不是每帧随机生成波。当前版本只有一套 JONSWAP 风浪谱。作为后续实现参考，Tidewater 的 [`4811ba4 / OceanFFT.js`](https://github.com/dgreenheck/tidewater/blob/4811ba48d795197de5621985f404e765c0b7c0ef/src/ocean/OceanFFT.js) 已将本地风浪与远来涌浪分成两套 WaveSystem，分别配置尺度、风向和方向分布；它的 ShoreWaves 则负责近岸浪。当前项目没有完整移植这套双波谱结构，全球相位缓存和近岸差值衔接是 Soomi 自己添加的处理。

后续应让外海的低频起伏也具有周期与方向分布，靠连续传播的波互相叠加形成长短不一的浪脊，并保留温和海况的能量水平。近岸水深、遮挡、反射和泡沫仍需对应实际入射波的相位，不能再用另一层独立时钟接替，也不能靠每帧随机噪声打散浪峰。双波谱与近岸入射相位的统一属于后续结构调整，本次资料核对尚未改动波形实现。

## 一波浪怎样变成泡沫

1. **透明涌浪推进。** [ShoreWaveField.ts](../src/ocean/ShoreWaveField.ts) 从现有海底与岸线生成到达时间场；[ShoreWaves.ts](../src/ocean/ShoreWaves.ts) 将持续推进的全局波形与近岸差值合成，并根据同一个时钟计算浪高、坡度与水面运动。几何和法线读取同一份结果，细碎纹理只补充表面细节。
2. **岩壁接触产生白水。** 根据岩岸法线、入射角和这波浪的接触时刻，估算短暂的撞岸白水与弱反射。完整的透明浪峰不会因为达到某个高度就在海中变成一条白线；岩岸转角降低反射置信度，避免整圈固定花边。
3. **泡沫随水运动。** [OceanFoam.ts](../src/ocean/OceanFoam.ts) 根据波形估算的水粒子速度输运泡沫，保留覆盖量和新鲜白水的历史。水面扩张与时间衰减会使它变薄，纹理坐标也随水移动。
4. **密集白水散开。** [FoamTexture.ts](../src/ocean/FoamTexture.ts) 的 R 通道记录到泡孔边缘的距离，G/B/A 分别提供小气泡、密度变化和泡孔随机值。[Water.ts](../src/ocean/Water.ts) 随覆盖量下降逐渐打开孔洞，再留下半透明短丝与少量气泡；纹理本身不决定何时凭空生成白水。

## 近似与限制

这是频谱海面、近岸波形和泡沫输运的组合。它没有求解三维流体、空气卷入或岩壁上的真实水流，白水也是表面密度与着色效果。岩壁接触和弱反射属于本项目的简化边界处理；上游沙滩的翻卷水帘、冲滩、喷溅和完整破浪过程没有引入。

实际海深参与传播速度和浪形计算，岸线距离控制接触区域。为了让温和的小浪在岛屿视角下可辨认，波形保留了适量的造型增强；这些参数由画面目标确定。
