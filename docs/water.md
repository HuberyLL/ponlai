# 水体实现说明

目标是有连续起伏、能够看见水下细节的深青色海水。小浪拍到岩岸时产生一点贴墙的碎白水，退浪后迅速散去；浪的主体保持透明。色彩、浪高和泡沫量按奇幻岛屿的画面调整。

## Tidewater 参考了什么

基础 FFT、光学着色和焦散来自 [tidewater 的 three.js / TSL 版 `fd6cae6`](https://github.com/dgreenheck/tidewater/tree/fd6cae6fa57343d344e5c008e1abda974c824b86)。频谱与泡沫参考其后来的原生 WebGPU 版 [`4811ba4`](https://github.com/dgreenheck/tidewater/tree/4811ba48d795197de5621985f404e765c0b7c0ef)，相关代码在这里改写为 TypeScript / TSL。

| 来源 | 本项目中的使用与改编 |
| --- | --- |
| [`4811ba4 / OceanFFT.js`](https://github.com/dgreenheck/tidewater/blob/4811ba48d795197de5621985f404e765c0b7c0ef/src/ocean/OceanFFT.js) | [OceanSpectrum.ts](../src/ocean/OceanSpectrum.ts) 移植 JONSWAP、有限水深 TMA 修正、随频率变化的方向分布和频率到波数的能量换算。[OceanFFT.ts](../src/ocean/OceanFFT.ts) 合成本地风浪与涌浪谱，并保留横向压缩产生的白帽历史。 |

新版 Tidewater 的 ShoreWaves 仍有独立周期的解析海滩浪，ShoreSim 使用那套浪的白水与水流。这里没有照搬它的海滩时钟、冲滩和翻卷水帘；FFT 与岩岸接触的连接、镜像反射、闭合岛屿遮挡是 Soomi 的简化处理。

## 上游默认参数与本项目的口径

参考版本 `4811ba4` 的 `OceanFFT` 默认合成两组造浪频谱。以下是构造器默认值，并非演示中所有可选海况或海滩浪的参数：

| 参数 | Tidewater 本地风浪 | Tidewater 远来涌浪 |
| --- | --- | --- |
| 造浪风速 | 7 米每秒 | 6 米每秒 |
| fetch | 120 千米 | 1200 千米 |
| 频谱方向 | 25° | 5° |
| `spreadBlend` | 0.85 | 1.0 |
| 频谱能量倍率 `scale` | 1.0 | 0.48 |
| 方向集中参数 `swell` | 0.05 | 0.9 |
| 峰值增强 | 3.3 | 3.3 |
| 短波衰减参数 | 0.01 | 0.1 |

共用横向压缩为 0.9，FFT 色散水深为 500 米，四层空间尺度为 733、157、33.3、7.1 米。来源见上方对应版本的 `OceanFFT.js`，默认应用在 `App.js` 中直接构造该海面。

上游 `scale` 是频谱能量乘数，本项目 `amplitude` 是合成高度的线性增益，数值不能直接对照。上游 `swell` 字段控制方向集中，不代表浪高；本项目改用 `swell.height` 显著波高与峰值周期控制这组波，再乘共用高度增益。频谱方向也须按各自 FFT 符号约定解释。上游较大的外海尺度与本项目温和、通透的小岛场景不同，当前没有照搬整套海况。

## 海面的浪怎样形成

本地风浪和远来涌浪各有频率与方向分布，在生成初始频谱时相加，随后共用一套 FFT 演化。涌浪参数中的“周期”是能量峰值附近的周期，不是每一波都以同样间距出现。不同频率、方向的波持续传播和叠加，浪峰的长度、强弱与相互交会随时间变化。

初始复数幅值用固定种子生成，播放时只推进各分量的色散相位，不逐帧重抽噪声。三层 256 × 256 FFT 纹理分别以 71.3、16、4 米的空间尺度覆盖水面。已经移除独立时钟的附加长浪和到达时间缓存；岸边两张动态缓存只提供弱反射、坡度、接触能量与运输速度，不替外海生成另一组波列。

每层输出四类纹理，几何、过滤后的坡度统计和泡沫历史分别保存：

| FFT 输出 | RGBA 通道 |
| --- | --- |
| displacement | 水平 X 位移、高度、水平 Z 位移、位移雅可比行列式 J |
| derivatives | 两个高度坡度、两个水平位移对角导数 |
| slope moments | 两个高度坡度的平方及乘积、有符号的水平交叉导数 |
| velocity | Airy 水平 X / Z 速度、垂直速度、持续衰减的白帽覆盖量 |

坡度均值和二阶矩采用相同的纹理过滤，差值估计像素未解析的各向异性波纹。遮挡等幅度权重也用于坡度方差，方差按权重的平方缩放；它与已经解析出的几何法线共同决定反射分布。

FFT 使用统一水深参数计算有限水深色散。它现在不读取每个位置的海底深度来改变传播路径，因此没有局部海底造成的波浪折射或浅化。实际海底仍参与可见的水下光线路径、颜色和焦散着色。

## 速度和接触白水

FFT 从同一组正、反时间相位计算线性 Airy 表面轨道速度，输出水平速度和垂直速度。它包含有限水深因子，独立于控制外观的横向压缩参数，也不是波峰的传播速度。

岩岸附近先投影到岩壁外侧的水域，读取经过低通和遮挡处理的实际 FFT 高度与水平速度。在墙外 0.16 米读取入射浪，只有水面抬高、速度指向岩壁时才连续增加接触能量；细毛细波的权重较低，避免每个小涟漪都冒出一粒白点。背浪接触点还单独按遮挡能量降低白水。生成范围以距岸 0.24 米的高斯尺度衰减，水侧只保留 0.02 米的入陆淡出，不再刻意留出离墙空隙。接触算完后，运输速度在贴岸处去掉指向岩石的分量，泡沫可以沿壁移动并随退水返回海里。

弱反射读取局部岩壁另一侧的镜像 FFT 样本，反转速度的法向分量，沿岸外几米平滑减弱。它沿用入射波的时间相位，没有独立周期。少量反射高度延拓到陆侧只为纹理过滤和坡度差分；陆地上没有水流或泡沫源。岸线转角降低几何可靠度，减弱不稳定的局部平面反射。

## 岛屿遮挡与缓存边缘

静态遮挡场沿主涌浪来向及 ±9°、±18° 共发出五条射线，检查现有岛屿岸线，并在水域内平滑。该场最低值为 0.06，但这不表示所有波的实际高度都剩 6%：最长 FFT 层使用 `0.12 + 0.88 × 遮挡值`，中层使用 `0.8 + 0.2 × 遮挡值`，细风纹保留。贴岸还有 0.45–1 的距离衰减，让岩壁附近保持温和起伏。

遮挡逐渐恢复外海强度，缓存外侧的遮挡修正严格归零；界外采样得到完整 FFT，而不是被冻结的边缘波形。水面法线由高度坡度与完整的水平位移雅可比共同计算，并补入遮挡、贴岸衰减和细波几何过渡的权重梯度。反射与 Snell 折射读取同一个解析法线，未解析的细波能量进入过滤后的坡度统计。

遮挡采用主方向近似，不能精确区分混合谱中每个来向；它不是衍射或绕岛能量求解。缓存只限制岩岸响应与泡沫的计算范围，外海 FFT 波不会在某个离岸阈值整条出现或消失。

## 泡沫怎样散开

[OceanFoam.ts](../src/ocean/OceanFoam.ts) 保存覆盖量、新鲜白水和随水移动的纹理坐标。每次更新沿水平速度回溯上一份历史；回溯的端点与中点检查岸线，阻止跨陆取样。水面扩张与时间衰减使泡沫变薄；浓白水塌散得更快，较薄的残留保留得稍久。新鲜白水单独保存冲击阶段，消退得更快。首次进入、时间回退、时间跳跃或频谱变化时从确定的历史时间段重新预热；同一时刻暂停时复用缓存。

[FoamTexture.ts](../src/ocean/FoamTexture.ts) 的 R 通道是到泡孔边缘的距离，G/B/A 分别提供小气泡、密度变化和泡孔随机值。当前温和海况不再显示浓厚白水主体。Water 的拍岸白边主要读取这一刻的 FFT 接触能量，最高覆盖权重为 0.32；历史泡沫只贡献很弱的残丝，避免先积累出一块脱离墙脚的泡沫斑。泡孔纹理尺度约 0.10 米，薄区打断成小片。这张确定性纹理只改变已有泡沫的形状，不决定哪里生成撞岸白水。外海白帽则由 FFT 横向压缩程度和短暂历史产生，与岩岸接触源分开。

接触泡沫的生成增益为 `3.2 /s`，由已有 FFT 接触能量控制，不另加随机白点。覆盖量基础衰减率从薄泡沫的 `1.5 /s` 平滑过渡到浓泡沫的 `2.4 /s`；新鲜通道为 `4.5 /s`，对应指数时间尺度约为 0.67、0.42 和 0.22 秒，并非固定存活时长。离岸超过 0.15 米后额外以 `4 × 超出距离` 的每秒速率消散，水流扩张也会使实际消退更快。水面与岩壁交界的视空间厚度淡出缩短至 0.005–0.045 米，让贴墙的薄白边可见；岸线源与深度仍阻止陆地白水。

## 保留的通透感

水体仍通过水下路径的吸收与散射表达深浅，而不是只靠水面透明度。当前共享吸收系数 RGB 为 `(0.28, 0.12, 0.10)`，散射为 `(0.02, 0.03, 0.03)`，单位均为每米；这些参数同时影响水面与海底照明。较低的悬浮散射保留水下细节，较长路径带来更深的青色。

太阳入水方向和观察折射光线遵循 Snell 定律；水下光束的面积投影及离水辐亮度换算继续使用主分支的介质传输处理。环境与屏幕空间反射、各向异性 Beckmann 太阳高光、焦散和温和浪峰透光共同参与画面。额外 glitter、sun sheen 和天空软限幅默认关闭，闪光主要来自已解析波面与过滤后的波纹统计。

泡沫沿用最大半球反射率 0.95 的 Lambert 光照，太阳与天空照明分别输入。细碎白水使用约一厘米以内的泡团、细孔与小气泡法线起伏。按 Tidewater SurfFoam 的做法，只对随流移动的纹理求导，再用水面切向梯度转换法线；密度只控制起伏强度，避免在每块泡沫边缘产生假高光。凹处可见度只减弱辐亮度，不额外增加环境填光。这是着色起伏，没有增加三维白水几何。

这轮调整适度恢复中尺度风浪的高度与长度，保留混合方向、连续相位和现有短波衰减。涌浪只小幅增加，不恢复独立周期的附加波列。基础粗糙度、光学参数、方向分布参数和短波过滤均保持原值，避免用整体反光变亮来制造鼓包感。

显著波高是频谱统计量，不是单个浪峰高度；实际离岸起伏还受风浪叠加、随机实现与画面衰减影响。当前正号逆 FFT 约定下，主传播方向与频谱中的波矢方向相反，岸边遮挡使用同一约定。

## 近似与限制

这是有限水深频谱海面、局部岩岸边界与表面泡沫输运的组合，没有求解三维流体、空气卷入、真实冲击压力或岩壁上的水流。Airy 速度来自线性波理论，几何横向压缩、主向遮挡与镜像反射仍是画面近似，不能把它们称为完整水动力边界。

FFT 空间纹理会重复，波数分辨率受层级尺寸限制；统一水深不能处理真实海底造成的折射与破浪。局部平面镜像对复杂凹岸、转角和多次反射有限，射线与泡沫网格也采用有限采样。上游海滩的翻卷、冲滩、喷溅和三维泡沫体积没有引入。参数与泡沫光照面向温和、通透的奇幻岛屿，而不是某个实测海况。
