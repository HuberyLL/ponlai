# 水体实现说明

目标是有连续起伏、能够看见水下细节的深青色海水。浪抵达岩岸后产生少量白水，随后散成泡孔和细丝；浪的主体保持透明。色彩、浪高和泡沫量按奇幻岛屿的画面调整。

## Tidewater 参考了什么

基础 FFT、光学着色和焦散来自 [tidewater 的 three.js / TSL 版 `fd6cae6`](https://github.com/dgreenheck/tidewater/tree/fd6cae6fa57343d344e5c008e1abda974c824b86)。频谱与泡沫参考其后来的原生 WebGPU 版 [`4811ba4`](https://github.com/dgreenheck/tidewater/tree/4811ba48d795197de5621985f404e765c0b7c0ef)，相关代码在这里改写为 TypeScript / TSL。

新版 Tidewater 的 ShoreWaves 仍有独立周期的解析海滩浪，ShoreSim 使用那套浪的白水与水流。这里没有照搬它的海滩时钟、冲滩和翻卷水帘；FFT 与岩岸接触的连接、镜像反射、闭合岛屿遮挡是 Soomi 的简化处理。

## 海面的浪怎样形成

本地风浪和远来涌浪各有频率与方向分布，在生成初始频谱时相加，随后共用一套 FFT 演化。涌浪参数中的“周期”是能量峰值附近的周期，不是每一波都以同样间距出现。不同频率、方向的波持续传播和叠加，浪峰的长度、强弱与相互交会随时间变化。

初始复数幅值用固定种子生成，播放时只推进各分量的色散相位，不逐帧重抽噪声。三层 256 × 256 FFT 纹理分别以 71.3、16、4 米的空间尺度覆盖水面。已经移除独立时钟的附加长浪和到达时间缓存；岸边两张动态缓存只提供弱反射、坡度、接触能量与运输速度，不替外海生成另一组波列。

FFT 使用统一水深参数计算有限水深色散。它现在不读取每个位置的海底深度来改变传播路径，因此没有局部海底造成的波浪折射或浅化。实际海底仍参与可见的水下光线路径、颜色和焦散着色。

## 速度和接触白水

FFT 从同一组正、反时间相位计算线性 Airy 表面轨道速度，输出水平速度和垂直速度。它包含有限水深因子，独立于控制外观的横向压缩参数，也不是波峰的传播速度。

岩岸附近先投影到岩壁外侧的水域，读取经过低通和遮挡处理的实际 FFT 高度与水平速度。只有水面抬高、速度指向岩壁时才连续增加接触能量；细毛细波的权重较低，避免每个小涟漪都冒出一粒白点。背浪接触点还单独按遮挡能量降低白水。接触算完后，运输速度在贴岸处去掉指向岩石的分量，泡沫可以沿壁移动并随退水返回海里。

弱反射读取局部岩壁另一侧的镜像 FFT 样本，反转速度的法向分量，沿岸外几米平滑减弱。它沿用入射波的时间相位，没有独立周期。少量反射高度延拓到陆侧只为纹理过滤和坡度差分；陆地上没有水流或泡沫源。岸线转角降低几何可靠度，减弱不稳定的局部平面反射。

## 岛屿遮挡与缓存边缘

静态遮挡场沿主涌浪来向及 ±9°、±18° 共发出五条射线，检查现有岛屿岸线，并在水域内平滑。该场最低值为 0.06，但这不表示所有波的实际高度都剩 6%：最长 FFT 层使用 `0.12 + 0.88 × 遮挡值`，中层使用 `0.8 + 0.2 × 遮挡值`，细风纹保留。贴岸还有 0.45–1 的距离衰减，让岩壁附近保持温和起伏。

遮挡逐渐恢复外海强度，缓存外侧的遮挡修正严格归零；界外采样得到完整 FFT，而不是被冻结的边缘波形。水面的大尺度法线补入遮挡和贴岸权重的梯度，避免高度被衰减后仍沿用未衰减的坡度。细纹法线强度可以按画面单独调整。

遮挡采用主方向近似，不能精确区分混合谱中每个来向；它不是衍射或绕岛能量求解。缓存只限制岩岸响应与泡沫的计算范围，外海 FFT 波不会在某个离岸阈值整条出现或消失。

## 泡沫怎样散开

[OceanFoam.ts](../src/ocean/OceanFoam.ts) 保存覆盖量、新鲜白水和随水移动的纹理坐标。每次更新沿水平速度回溯上一份历史；回溯的端点与中点检查岸线，阻止跨陆取样。水面扩张与时间衰减使泡沫变薄，新鲜白水消退得更快。首次进入、时间回退、时间跳跃或频谱变化时从确定的历史时间段重新预热；同一时刻暂停时复用缓存。

[FoamTexture.ts](../src/ocean/FoamTexture.ts) 的 R 通道是到泡孔边缘的距离，G/B/A 分别提供小气泡、密度变化和泡孔随机值。Water 随覆盖量降低逐渐打开孔洞，留下半透明短丝与少量气泡；这张确定性纹理只改变已有泡沫的形状，不决定哪里生成撞岸白水。外海白帽则由 FFT 横向压缩程度和短暂历史产生，与岩岸接触源分开。

## 保留的通透感

水体仍通过水下路径的吸收与散射表达深浅，而不是只靠水面透明度。当前共享吸收系数 RGB 为 `(0.28, 0.12, 0.10)`，散射为 `(0.02, 0.03, 0.03)`，单位均为每米；这些参数同时影响水面与海底照明。较低的悬浮散射保留水下细节，较长路径带来更深的青色。折射、环境与屏幕空间反射、细小闪光、焦散和温和浪峰透光继续参与画面。

## 当前场景默认值

以下来自 `src/main.ts` 的场景设置及 OceanFFT / ShoreWaves 的未覆盖参数，不是构造器中所有通用默认值。

| 参数 | 当前值 |
| --- | --- |
| 风速 / fetch | 3 米每秒 / 1500 米 |
| 风浪方向参数 / 方向分布混合 | 40° / 0.52 |
| 共用幅度增益 / 横向压缩 | 0.68 / 0.5 |
| FFT 统一色散水深 | 8 米 |
| 涌浪显著波高参数 | 0.16 米，定义为 `4 × 标准差`，在共用幅度增益之前归一化 |
| 涌浪峰值周期 / 相对方向偏移 | 3.4 秒 / 20° |
| 涌浪方向分布混合 / 峰值增强 | 0.85 / 1.8 |
| 岩壁反射系数 / 细浪法线权重 | 0.14 / 0.68 |

显著波高是频谱统计量，不是单个浪峰高度；实际离岸起伏还受风浪叠加、随机实现与画面衰减影响。当前正号逆 FFT 约定下，主传播方向与频谱中的波矢方向相反，岸边遮挡使用同一约定。

## 近似与限制

这是有限水深频谱海面、局部岩岸边界与表面泡沫输运的组合，没有求解三维流体、空气卷入、真实冲击压力或岩壁上的水流。Airy 速度来自线性波理论，几何横向压缩、主向遮挡与镜像反射仍是画面近似，不能把它们称为完整水动力边界。

FFT 空间纹理会重复，波数分辨率受层级尺寸限制；统一水深不能处理真实海底造成的折射与破浪。局部平面镜像对复杂凹岸、转角和多次反射有限，射线与泡沫网格也采用有限采样。上游海滩的翻卷、冲滩、喷溅和三维泡沫体积没有引入。参数与泡沫光照面向温和、通透的奇幻岛屿，而不是某个实测海况。
